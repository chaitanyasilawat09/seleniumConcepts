## 5. TEST COVERAGE METRICS

### Requirement Coverage

**Formula:**
```
Requirement Coverage = (Requirements Tested / Total Requirements) × 100
```

**Example:**
- Total requirements: 100
- Requirements tested: 90
- Coverage: 90%

### Test Case Coverage

**Formula:**
```
Test Case Coverage = (Test Cases Executed / Total Test Cases) × 100
```

**Example:**
- Total test cases: 500
- Test cases executed: 450
- Coverage: 90%

### Code Coverage

**Types:**
- Line coverage
- Branch coverage
- Path coverage
- Function coverage

**Tools:**
- JaCoCo (Java)
- Istanbul (JavaScript)
- Coverage.py (Python)

### Feature Coverage

**Formula:**
```
Feature Coverage = (Features Tested / Total Features) × 100
```

**Example:**
- Total features: 20
- Features tested: 18
- Coverage: 90%

### Interview Questions

## 12. EXTENT REPORTS

### Setup

**Maven Dependency:**
```xml
<dependency>
    <groupId>com.aventstack</groupId>
    <artifactId>extentreports</artifactId>
    <version>5.1.1</version>
</dependency>
```

### Implementation

```java
public class ExtentManager {
    private static ExtentReports extent;
    private static ExtentTest test;
    
    public static ExtentReports getInstance() {
        if (extent == null) {
            extent = new ExtentReports();
            ExtentSparkReporter spark = new ExtentSparkReporter("target/extent-report.html");
            extent.attachReporter(spark);
        }
        return extent;
    }
    
    public static void createTest(String testName) {
        test = extent.createTest(testName);
    }
    
    public static void log(String message) {
        test.log(Status.INFO, message);
    }
    
    public static void pass(String message) {
        test.pass(message);
    }
    
    public static void fail(String message) {
        test.fail(message);
    }
    
    public static void flush() {
        extent.flush();
    }
}
```

### TestNG Listener

```java
public class ExtentListener implements ITestListener {
    @Override
    public void onTestStart(ITestResult result) {
        ExtentManager.createTest(result.getMethod().getMethodName());
    }
    
    @Override
    public void onTestSuccess(ITestResult result) {
        ExtentManager.pass("Test passed");
    }
    
    @Override
    public void onTestFailure(ITestResult result) {
        ExtentManager.fail("Test failed: " + result.getThrowable().getMessage());
    }
    
    @Override
    public void onFinish(ITestContext context) {
        ExtentManager.flush();
    }
}
```

## 14. CUSTOM REPORTING

### HTML Report

```java
public class HTMLReportGenerator {
    public void generateReport(List<TestResult> results) {
        StringBuilder html = new StringBuilder();
        html.append("<html><body>");
        html.append("<h1>Test Report</h1>");
        html.append("<table>");
        html.append("<tr><th>Test</th><th>Status</th></tr>");
        
        for (TestResult result : results) {
            html.append("<tr>");
            html.append("<td>").append(result.getName()).append("</td>");
            html.append("<td>").append(result.getStatus()).append("</td>");
            html.append("</tr>");
        }
        
        html.append("</table></body></html>");
        
        Files.write(Paths.get("report.html"), html.toString().getBytes());
    }
}
```

### Excel Report

```java
public class ExcelReportGenerator {
    public void generateReport(List<TestResult> results) throws IOException {
        Workbook workbook = new XSSFWorkbook();
        Sheet sheet = workbook.createSheet("Test Results");
        
        Row headerRow = sheet.createRow(0);
        headerRow.createCell(0).setCellValue("Test Name");
        headerRow.createCell(1).setCellValue("Status");
        headerRow.createCell(2).setCellValue("Duration");
        
        int rowNum = 1;
        for (TestResult result : results) {
            Row row = sheet.createRow(rowNum++);
            row.createCell(0).setCellValue(result.getName());
            row.createCell(1).setCellValue(result.getStatus());
            row.createCell(2).setCellValue(result.getDuration());
        }
        
        try (FileOutputStream out = new FileOutputStream("report.xlsx")) {
            workbook.write(out);
        }
    }
}
```

### Email Report

```java
public class EmailReportSender {
    public void sendReport(String reportPath) {
        Properties props = new Properties();
        props.put("mail.smtp.host", "smtp.example.com");
        props.put("mail.smtp.port", "587");
        
        Session session = Session.getInstance(props);
        
        try {
            MimeMessage message = new MimeMessage(session);
            message.setFrom("qa@example.com");
            message.setRecipients(Message.RecipientType.TO, "team@example.com");
            message.setSubject("Test Report");
            
            MimeBodyPart messageBodyPart = new MimeBodyPart();
            messageBodyPart.setText("Please find attached test report");
            
            MimeBodyPart attachmentPart = new MimeBodyPart();
            attachmentPart.attachFile(new File(reportPath));
            
            Multipart multipart = new MimeMultipart();
            multipart.addBodyPart(messageBodyPart);
            multipart.addBodyPart(attachmentPart);
            
            message.setContent(multipart);
            
            Transport.send(message);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```
