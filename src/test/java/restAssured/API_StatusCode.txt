                           Create → `201` (not `200`)
- Delete/PUT with no response body → `204`
- Async job accepted → `202`
- Validation failure → `422` for semantic errors, `400` for malformed syntax
- 401 vs 403: 401 = "who are you?", 403 = "I know you, and no."
- 404 vs 410: 404 = "doesn't exist (or never did)", 410 = "existed, now gone forever"
- Rate limits → `429` + `Retry-After`
